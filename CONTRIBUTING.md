# Contributing

Thanks for helping. The most useful contribution is **a real situation where a skill gave a weak result**.

## Report a weak result (issue)

Include:
1. Which skill
2. Your prompt (remove names and private details)
3. What the AI produced
4. What you expected
5. Tool and model used (e.g. Antigravity, Claude)

## Propose a change (pull request)

1. Fork and branch.
2. Read `AGENTS.md`, `docs/SKILL-AUTHORING.md`, and `docs/LEGAL-SAFETY.md`.
3. Keep `SKILL.md` short; put detail in `references/`.
4. Add or update test prompts in `docs/TESTING-EVAL.md` and note the results.
5. Update the README table and CHANGELOG.
6. Describe what changed and why.

## Rules

- No invented prices, laws, statistics, or testimonials.
- No real client data. Anonymize everything.
- Legal and tax content: draft and checklist only, with a clear "check with a professional" note.
- Be kind in discussions. Assume good intent.

## New skill ideas

Open an issue first with: who needs it, the problem, an example input and the output they'd want, and what the skill must refuse to do.
